# Servo Motor Sweep

Components:
- Arduino Uno
- SG90 Servo Motor
- 10k Potentiometer
- Push Button
- 10kΩ Resistor

Features:
- Potentiometer controls servo angle from 0° to 180°.
- Current angle is displayed on the Serial Monitor.
- Pressing the button makes the servo perform one full sweep:
  0° → 180° → 0°.
- Developed and tested in Tinkercad.

# Keypad + LCD Password Protected Access System

## Components Used
- Arduino Uno
- 4x4 Membrane Keypad
- 16x2 LCD
- Green LED
- Red LED
- Piezo Buzzer
- 220Ω Resistors
- 10k Potentiometer

## Features
- Displays "ENTER PIN:" on LCD.
- Correct PIN shows "ACCESS GRANTED" and turns ON Green LED.
- Wrong PIN shows "ACCESS DENIED", turns ON Red LED and activates buzzer.
- System locks for 10 seconds after 3 wrong attempts.
- Serial Monitor displays system status.

## Password
1408

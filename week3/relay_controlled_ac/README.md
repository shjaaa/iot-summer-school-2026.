# Relay-Controlled AC Device Simulation

Components Used:
- Arduino Uno
- DHT22 Sensor
- LED (simulating relay/AC appliance)
- Push Button
- 220Ω Resistor

Features:
- Relay turns ON when temperature > 32°C.
- Relay turns OFF when temperature < 28°C (hysteresis).
- Manual override button to toggle relay state.
- Serial Monitor logs temperature and relay state changes.

Simulation: Wokwi

# LED Blink Project

## Description
This project demonstrates a basic LED blinking application using Arduino. The LED connected to pin 13 blinks continuously.

## Hardware Required
- Arduino Uno
- LED
- 220Ω Resistor
- Breadboard
- Jumper Wires
- Potentiometer (for speed control version)

## Circuit Connections
- LED anode (+) → Pin 13
- LED cathode (-) → GND through 220Ω resistor
- Potentiometer middle pin → A0
- Potentiometer side pins → 5V and GND

## Features
- Basic LED blinking
- Serial blink counter
- Adjustable blink speed using potentiometer

## Code Versions

- v1.1 : Serial Blink Counter
